# SUDUEL（数独デュエル）

数独の盤面を使った2人対戦ゲームです。交互に数字を置き、先に置けなくなった方が負け。

🎮 **プレイはこちら** → https://last-cell-a21fd.web.app

---

## ゲームの概要

数独のルール上正しい数字なら、どのマスにでも置けます。自分のターンに置ける場所がなくなったら負けです。シンプルなルールの中に、残り手数の奇偶をめぐる読み合いが生まれます。

## 機能

### vs AI
- 3段階の難易度（弱い・普通・強い）
  - **弱い**：ランダムに着手
  - **普通**：残り有効手数の奇偶を1手先まで評価
  - **強い**：2手先まで読み、相手の最善の応手を考慮して着手
- アンドゥ機能
- 制限時間モード（30秒・60秒）

### オンライン対戦
- 4桁のルームIDで対戦相手を招待
- Firebase Realtime Databaseによる着手のリアルタイム同期
- 相手の退出を検知して通知
- 再戦機能（新しいルームを自動で作り、同じ相手と続けて対戦）

### 振り返り・その他
- 全手順を振り返れる棋譜機能
- 残り有効手数の推移グラフ（クリックでその時点の盤面に移動）
- 難易度別の通算成績（localStorageに保存）
- 効果音（Web Audio API）
- スマホ対応

## 工夫した点

- **再戦時のバグ対策**：最初は同じルームを使い回していたため、前の対局の着手が混ざる不具合が起きた。再戦のたびに新しいルームを作る方式に変えて解決した。
- **AIの考え方**：このゲームは残り有効手数の奇偶が勝敗を左右するため、AIはその性質を使って手を評価している。
